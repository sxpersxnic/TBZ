# M450 – Applikationen testen

> **Application testing** · Year 3 (2025/26) · Autumn semester (HS) · Done

Testing strategies and levels, unit and interface tests, test automation, CI/CD pipelines, code reviews and test-driven development.

> [!TIP]
> The notes often link to projects in the `x-res` folder, which contains the example applications and resources used for the exercises.
> To keep the repository small, these directories are zipped. Unzip them before running the apps.
